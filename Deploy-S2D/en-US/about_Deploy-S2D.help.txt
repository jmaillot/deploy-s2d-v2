TOPIC
    about_Deploy-S2D

SHORT DESCRIPTION
    Two-phase Storage Spaces Direct deployment for 2 to 16 Windows Server nodes.

LONG DESCRIPTION
    The Deploy-S2D module deploys a Storage Spaces Direct (S2D) cluster in two
    phases with different blast radiuses, which is why they are separate commands:

    Phase 1 - Start-S2DNodePrep (run LOCALLY on EACH node, elevated):
        Validates hardware (4+ physical NICs, 10 Gbps + RDMA on storage and
        LiveMig, poolable disks), renames NICs, sets jumbo MTU and static
        storage IPs, configures QoS/DCB and RDMA, builds the vSwitch, disables
        VMQ/RSC on team members, binds the live migration network.

    Phase 2 - New-S2DCluster (run ONCE from one node):
        Validates, creates the cluster, sets quorum, enables S2D, creates
        VolumeCount CSV volumes (ReFS) with the selected resiliency
        (Mirror/NestedMirror/NestedParity on 2 nodes, Mirror on 3,
        DualParity/MirrorAcceleratedParity on 4+ - one value for all
        volumes, or one per volume), pins tiers per volume with
        -StorageTier (SSD,HDD side by side needs NVMe cache), constrains
        SMB Multichannel, renames networks. Auto sizing splits usable
        capacity by efficiency; Fixed validates footprints. A
        drive-based reserve (or -CapacityReservePercent, larger wins) is
        kept unless -UseFullPool. Clusters beyond 2 nodes need switched
        fabrics (one switch per fabric minimum) - direct-connect cables
        only work at 2 nodes.

    Start-S2DDeployment is a back-compat wrapper around both. Prefer the phase
    functions. Scripts/ holds the safe-reboot runbook (Reboot-S2D.ps1) and
    the vendored Clear-PhysicalDiskHealthData.ps1 helper.

EXAMPLES
    PS> Start-S2DNodePrep -StorageAIP 192.168.200.1 -StorageBIP 192.168.201.1 -WhatIf
    PS> New-S2DCluster -ClusterName CL -ClusterNodes HV1,HV2 -ClusterIP 192.168.1.240 -WhatIf
    PS> New-S2DCluster -VolumeName CSV -VolumeCount 2 -StorageTier SSD,HDD -Resiliency Mirror,NestedParity -SizingMode Auto
